# Snake

A simple Snake game built with plain HTML, CSS, and JavaScript. It has no dependencies or build step.

## How to play

- Use the arrow keys or swipe to move.
- Eat the red squares to grow and score points.
- Avoid the walls and your own body.
- Your best score is saved in your browser.

## Run it

Download `index.html` and open it in any browser.

## Play it online with GitHub Pages

1. Upload `index.html` and `README.md` to a new GitHub repo.
2. Go to **Settings > Pages**.
3. Under **Branch**, pick `main` and click **Save**.
4. After a minute or two, your game will be live at `https://<your-username>.github.io/<repo-name>/`.
